# Required References for every PRD

> Every PRD in `openspec/planning/prds/` must reference these canonical files.
> Citing the references (rather than duplicating content) keeps the PRDs
> compact while ensuring every PRD is "complete" — the model, the project
> context, the testing capabilities, and the stack are all bound to each PRD.

## How to use this in a PRD

Each PRD has a `## Required References` section near the top:

```markdown
## Required References

> Every PRD is complete when read together with these canonical files.
>
> - **Data Model**: [`modelo_datos_er.mmd`](../../../modelo_datos_er.mmd) — authoritative schema (1451 lines)
> - **Project Context**: [`openspec/PROJECT_CONTEXT.md`](../../PROJECT_CONTEXT.md)
> - **Testing Capabilities**: [`openspec/TESTING_CAPABILITIES.md`](../../TESTING_CAPABILITIES.md)
> - **Stack / Conventions**: [`AGENTS.md`](../../../AGENTS.md)
> - **Roadmap**: [`openspec/_meta/roadmap.md`](../roadmap.md)
> - **Iteration Plan**: [`openspec/_meta/iteration-plan.md`](../iteration-plan.md)
> - **Shared PRD Docs**: [`_shared/`](.) — UUIDv4 strategy, SOLID principles, CodeGraph usage, layer impact map
>
> This PRD does NOT duplicate the content of those files; it cites them.
> Reviewers: read this PRD together with the references above.

```

## Audit

When a PRD is `Approved` or `Implemented`, the Required References section is the audit trail: it proves the PRD was scoped against the canonical files at that point in time. If a canonical file changes after a PRD is approved, the PRD must be re-reviewed.
